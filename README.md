#  ShopVibe

ShopVibe is a modern and responsive shopping website built using HTML, Tailwind CSS, and JavaScript DOM Manipulation

The project demonstrates interactive frontend features such as:
- Dynamic product cards
- Wishlist functionality
- Search filtering
- Dark/Light mode
- Mobile navigation menu
- Toast notifications
- Dropdown categories
-  welcome message

# Features

1. Responsive Navigation
2. Dark / Light Theme
3. Dynamic Product Cards
4. Products generated using JavaScript
5. Hover animations and transitions
6. Add-to-wishlist functionality
7. Personalized Greeting
8.Toast Notifications
9.Fully Responsive Design
10.Built with Tailwind CSS utility classes
11.Mobile-friendly layout

# Tools Used

- HTML5
- Tailwind CSS
- JavaScript (DOM Manipulation)
